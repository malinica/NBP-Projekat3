# NBP-Projekat3

## Description
The project was developed as part of the **Advanced Databases** course.  
It is a **web application for real estate management** that allows users to list properties, search for available real estate, track offers, and analyze the market.  
The application is divided into **backend** (API service in .NET) and **frontend** (user interface in React/TypeScript), with **MongoDB** as the main database.

## Goal
The goal of the project is to demonstrate the integration of advanced databases with modern web applications through a practical real estate scenario.  
Users can create accounts, add property listings, search for real estate and ask questions via forum.

## Features
- **User registration and login**
- **Adding property listings** 
- **Viewing available properties** with detailed information
- **Search functionality** – filter by location, price, type, or owner
- **Asking via forum** - 
- **Administration** – manage users and property listings

## Technologies
- **Backend**: C#/.NET 9.0, REST API  
- **Frontend**: TypeScript, React, CSS  
- **Database**: MongoDB  
- **Docker** – service orchestration  

## Running the project
1. **Navigate to the ../backend folder and run the command `docker-compose up -d`**  
2. **Navigate to the ../backend/API folder and run the command `dotnet run`**  
3. **Navigate to the ../frontend folder and run the command `npm run start`**
